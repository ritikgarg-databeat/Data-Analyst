# @data-analyst-lab/web

The Next.js frontend for **Personal Data Analyst Lab**. See the [repo-root README](../../README.md)
for setup, running, and testing instructions, and [`docs/architecture.md`](../../docs/architecture.md)
for how this app fits into the rest of the monorepo.

Quick reference (run from the repo root so the `@data-analyst-lab/shared` workspace package resolves):

```bash
npm run dev:web         # dev server → http://localhost:3000
npm run build:web       # production build
npm run test:web        # Vitest + Testing Library
npm run lint:web        # ESLint
npm run typecheck:web   # tsc --noEmit
```
